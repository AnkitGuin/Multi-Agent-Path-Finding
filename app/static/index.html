Reading the demo

Independent A* ignores other agents — watch the red flashes: every flash is a collision the fleet would actually suffer. That is the coordination burden an instance imposes.
Prioritized Planning plans agents one after another against a space-time reservation table. It is fast, but a later agent is never allowed to displace an earlier one, so it can fail even when a solution exists — and its routes can be visibly longer.
CBS starts from the independent plan and resolves one conflict at a time by branching on constraints, so it returns a provably conflict-free (SOC-optimal) plan — at a computational cost that grows steeply with the number of agents.
